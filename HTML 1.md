* <p> used to write paragraphs 

&#x20;   Ex -> <p> In HTML, an HTML document is divided into two primary sections: the <head> (header) and the <body> (body). The fundamental difference is that the <head> contains invisible             metadata and configuration data, while the <body> contains all the visible content shown to the user </p>    this will print like a para

* The <br> tag is used to insert a single line break in a text block. It is a "void element," meaning it stands alone and does not need a closing tag (</br>).



* The <hr> tag stands for Horizontal Rule and is used to create a thematic break between paragraph-level elements on a webpage. In visual browsers, it renders as a horizontal line running across the page. It is also void element 



* The <pre> tag stands for Preformatted Text. It is used to display text exactly as it is written in your HTML source code.
